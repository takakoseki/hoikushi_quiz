社会的養護の出題範囲

社会的養護は、家庭で育てられない子どもへの公的な養育を学ぶ科目です。施設養護・里親制度・自立支援など、現場に直結した内容が出題されます。

  • 社会的養護の基本理念・原則
  • 施設養護（児童養護施設・乳児院など）
  • 家庭的養護・里親制度
  • 自立支援・アフターケア
  • 児童相談所の役割
  • 社会的養護に関する法令

頻出テーマと学習ポイント

社会的養護の基本理念と原則

「家庭的養護の推進」「個別化」「継続性」「自立支援」などの原則を整理しましょう。国連の「子どもの代替的養護に関するガイドライン」も出題されます。施設養護と家庭的養護の違いを明確に理解することが重要です。

  • 家庭的養護
  • 個別化の原則
  • 継続性
  • 自立支援
  • 代替的養護

里親制度と施設種別

里親の4種類（養育里親・専門里親・養子縁組里親・親族里親）の違いは頻出です。施設種別では乳児院・児童養護施設・児童自立支援施設・母子生活支援施設などの対象・目的・入所要件を整理しましょう。

  • 養育里親
  • 専門里親
  • 乳児院
  • 児童養護施設
  • ファミリーホーム

自立支援とアフターケア

施設退所後の自立支援（退所後アフターケア事業）と、措置延長（22歳まで）の仕組みを押さえましょう。社会的養護自立支援事業の内容や、退所した子どもへの相談・居場所支援も出題されます。

  • 自立援助ホーム
  • 措置延長
  • アフターケア
  • 退所支援
  • 社会的養護経験者

社会的養護の例題

実際に出題される形式の一部です。緑色が正解の選択肢です。残り110問は「クイズをはじめる」から無料で解けます。

例題 1

「社会的養護」の対象となる子どもの説明として、最も適切なものを一つ選びなさい。

  1. 保護者のない児童や、保護者に監護させることが適当でない児童を、公的責任で社会的に養育・保護するとともに、養育に困難を抱える家庭への支援を行うこと
  2. すべての就学前児童を対象に、保護者の就労の有無にかかわらず行う保育のこと
  3. 障害のある児童に対して行う医療的ケアのみを指す
  4. 経済的に困窮する家庭の児童に対してのみ行われる現金給付のこと

正解：A　社会的養護は「保護者のない児童や、保護者に監護させることが適当でない児童を、公的責任で社会的に養育・保護するとともに、養育に困難を抱える家庭への支援を行うこと」と定義される(厚生労働省)。「子どもの最善の利益のために」「社会全体で子どもを育む」という2つの基本理念の下、家庭養護と施設養護の連続性の中で展開される。

例題 2

「ライフストーリーワーク」の目的として正しいものはどれか？

  1. 将来の職業選択を支援すること
  2. 自分の過去・現在・未来を理解しアイデンティティを確立すること
  3. 実親との再統合を促進すること
  4. 施設での日課・生活習慣を整えること

正解：B　ライフストーリーワークは、社会的養護のもとで暮らす子どもが自分の生い立ちや過去を整理し、アイデンティティを確立するための支援手法です。なぜ家庭を離れて暮らすことになったのかを子ども自身が理解できるよう支えるもので、職業選択の支援や実親との再統合を目的とするものではありません。

例題 3

「ケアリーバー」の説明として正しいものはどれか？

  1. 施設に入所したばかりの子ども
  2. 里親家庭を卒業した若者
  3. 社会的養護（施設・里親）を退所・措置解除した若者
  4. 社会的養護の支援を受けている最中の子ども

正解：C　ケアリーバーとは、施設や里親家庭などの社会的養護を退所・措置解除した若者を指します。退所後は住居・就労・経済面での支えを得にくく、孤立や生活困難が社会問題となっています。措置延長や自立援助ホーム、アフターケア事業といった支援の仕組みとあわせて理解しておきましょう。

例題 4

児童養護施設に関する記述として、正しいものを一つ選びなさい。

  1. 児童福祉法第41条に基づき、保護者のない児童、虐待されている児童その他環境上養護を要する児童を入所させて、これを養護する施設である
  2. 対象年齢は原則として乳児を除く18歳未満であるが、必要がある場合には乳児も入所できる
  3. 退所した者に対する相談その他の自立のための援助を行うことも目的とされている
  4. 上記のすべてが正しい

正解：D　児童養護施設は児童福祉法第41条に基づき、保護者のない児童・虐待されている児童その他環境上養護を要する児童(「安定した生活環境の確保その他の理由により特に必要のある場合には、乳児を含む」)を入所させて養護し、あわせて退所者への相談・自立援助を行う施設である。全選択肢が正しいので正解はD。

例題 5

令和6年4月から施行された改正児童福祉法により新設された児童福祉施設として、正しいものを一つ選びなさい。

  1. 里親支援センター
  2. 地域子育て支援センター
  3. 児童家庭支援センター
  4. 子育て世代包括支援センター

正解：A　令和4年改正児童福祉法(令和6年4月施行)により、児童福祉法第7条の児童福祉施設に「里親支援センター」が追加され、新たな児童福祉施設(13番目の施設種別)として位置づけられた。里親のリクルート、里親等への研修、里親委託の推進、委託後の支援等を一体的に行う。Cの児童家庭支援センターは既存の児童福祉施設、B・Dは児童福祉施設ではなく別制度の事業・拠点である。

よくある質問

社会的養護の効率的な勉強法を教えてください
施設の種別と里親の種別を正確に整理することが最優先です。それぞれの対象年齢や目的を一覧表にまとめると混同を防げます。そのうえで家庭的養護や個別化といった基本理念を重ねて理解すると、事例問題にも対応しやすくなります。
里親にはどのような種類がありますか
養育里親、専門里親、養子縁組里親、親族里親の4種類です。専門里親は虐待や障害などにより専門的な支援を要する子どもを対象とする点、養子縁組里親は養子縁組を前提とする点が区別のポイントになります。
児童福祉施設の種類と対象を教えてください
乳児院、児童養護施設、母子生活支援施設、児童心理治療施設、児童自立支援施設、自立援助ホームなどがあります。それぞれ対象となる子どもの年齢や状況が異なるため、名称と対象をセットで覚えましょう。小規模住居型児童養育事業（ファミリーホーム）は施設ではなく事業である点も要注意です。
社会的養護の基本原理を教えてください
家庭的養護と個別化、発達の保障と自立支援、回復をめざした支援、家族との連携・協働、継続的支援と連携アプローチ、ライフサイクルを見通した支援の6つです。理念を問う設問では、これらの文言がそのまま選択肢に使われることが多くあります。
社会的養護と子ども家庭福祉はどう違いますか
子ども家庭福祉が子ども家庭施策全般を扱うのに対し、社会的養護は家庭で暮らすことが難しい子どもへの代替養育に特化しています。児童相談所や措置の仕組みなど重なる部分もあるため、共通する制度は一度にまとめて学ぶと効率的です。
社会的養護は教育原理と出題範囲が重なりますか？
内容の重なりはほとんどありません。社会的養護は児童福祉施設や里親など養護の実践と制度が中心で、教育原理は学校教育制度と教育思想が中心です。ただし合否の扱いだけは連動しており、同じ回の筆記試験で両科目とも満点の6割以上を得点しないと合格になりません。範囲は別々に学ぶ必要があるのに合否は一体という点が、この2科目の対策を難しくしています。学習時間はそれぞれ別に確保してください。
