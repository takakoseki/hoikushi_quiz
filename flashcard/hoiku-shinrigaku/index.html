保育の心理学の出題範囲

保育士試験【保育の心理学】は、子どもの発達・心理を学ぶ科目です。ピアジェやエリクソンの発達理論、ボウルビィの愛着理論など著名な研究者の理論が頻出で、一問一答での繰り返し学習が効果的です。106問を無料で練習できます。

  • 発達理論（ピアジェ・エリクソン・ヴィゴツキーなど）
  • 愛着理論（ボウルビィ）と愛着の発達段階
  • 言語・認知発達と象徴機能
  • 社会性・道徳性の発達（コールバーグなど）
  • 子どもの遊びと発達（パーテンの遊びの分類）
  • 障害のある子どもの発達支援
  • 保育における観察・記録・省察

頻出テーマと学習ポイント

発達理論と代表的な学者

ピアジェの認知発達段階（感覚運動期〜形式的操作期）とヴィゴツキーの「発達の最近接領域」は毎年頻出です。エリクソンの心理社会的発達段階（信頼感・自律性・主体性など）も確実に押さえましょう。

  • ピアジェ
  • ヴィゴツキー
  • エリクソン
  • コールバーグ
  • 発達の最近接領域

愛着理論とアタッチメント

ボウルビィの愛着理論とエインズワースの「ストレンジ・シチュエーション法」はセットで理解することが重要です。安定型・回避型・抵抗型・無秩序型の4分類と保育実践での意義を学習しましょう。

  • ボウルビィ
  • エインズワース
  • 安定型愛着
  • 内的作業モデル
  • ストレンジ・シチュエーション

遊びの発達と観察・記録

パーテンの遊びの分類（傍観・一人遊び・平行遊び・連合遊び・協同遊び）は頻出です。エピソード記録や保育ドキュメンテーションなど、子どもの育ちを記録・省察する方法も押さえておきましょう。

  • パーテン

保育の心理学の例題

実際に出題される形式の一部です。緑色が正解の選択肢です。残り101問は「クイズをはじめる」から無料で解けます。

例題 1

ピアジェ(J. Piaget)の認知発達理論における4段階について、段階名と年齢のおおよその組み合わせとして、誤っているものを一つ選びなさい。

  1. 感覚運動期 ─ 0〜2歳頃
  2. 前操作期 ─ 2〜7歳頃
  3. 具体的操作期 ─ 7〜11歳頃
  4. 形式的操作期 ─ 3〜6歳頃

正解：D　ピアジェの発達4段階は、①感覚運動期(0〜2歳頃)、②前操作期(2〜7歳頃)、③具体的操作期(7〜11歳頃)、④形式的操作期(11歳以降)と区分される。形式的操作期は11歳以降であり、3〜6歳は前操作期の前半にあたるため、Dが誤り。

例題 2

エリクソン(E. H. Erikson)の心理社会的発達理論における青年期の発達課題として、正しいものを一つ選びなさい。

  1. 基本的信頼 対 不信
  2. 自律性 対 恥・疑惑
  3. 同一性(アイデンティティ) 対 同一性拡散
  4. 生殖性(ジェネラティビティ) 対 停滞

正解：C　エリクソンの8段階では、青年期の課題は「同一性(アイデンティティ)対 同一性拡散(役割混乱)」である。Aは乳児期、Bは幼児前期、Dは成人期の課題。エリクソンは青年期における「モラトリアム(猶予期間)」の意義も強調した。

例題 3

ヴィゴツキーが提唱した「発達の最近接領域（ZPD）」の説明として正しいものはどれか？

  1. 子どもが一人でできる課題の難易度範囲
  2. 子どもが一人ではできないが適切な援助があればできる課題の領域
  3. 子どもの遺伝的潜在能力
  4. 子どもの社会的発達の到達目標

正解：B　発達の最近接領域（ZPD）とは、子どもが一人ではできないが教師や仲間の援助があればできる課題の領域のことです。この領域に働きかけることが発達を促すとされ、援助を段階的に減らしていく「足場かけ（スキャフォールディング）」の考え方につながります。ピアジェとの立場の違いも問われます。

例題 4

ボウルビィ(J. Bowlby)のアタッチメント(愛着)理論に関する記述として、誤っているものを一つ選びなさい。

  1. アタッチメントとは、特定の養育者との間に形成される情緒的な絆であり、子どもが不安や恐れを感じた際に養育者に接近して安心を得ようとする心的傾向を指す
  2. 母性剥奪(maternal deprivation)が子どもの発達に深刻な影響を及ぼすことを指摘した
  3. アタッチメントの発達には「前愛着段階」「愛着形成段階」「明確な愛着段階」「目標修正的協調段階」の4段階がある
  4. アタッチメントは遺伝的に決定されており、養育環境の影響はほとんど受けない

正解：D　ボウルビィのアタッチメント理論は、乳幼児の生得的な愛着行動システムの意義を認めつつ、質の異なるアタッチメントは養育者との相互作用(養育の質)によって形成されるとする。養育環境の影響を軽視する立場ではない(Dが誤り)。母性剥奪・ホスピタリズムの研究も重要。

例題 5

ピアジェの認知発達段階において「自己中心性」が特徴的な段階はどれか？

  1. 感覚運動期
  2. 前操作期
  3. 具体的操作期
  4. 形式的操作期

正解：B　ピアジェの前操作期（2〜7歳頃）では、自分の視点からしか物事を見られない「自己中心性」が特徴です。三つ山問題でこれを示しました。感覚運動期は感覚と運動を通じた認識、具体的操作期は保存の概念の成立、形式的操作期は抽象的思考が特徴です。段階の順序と特徴を対応させて覚えましょう。

よくある質問

保育の心理学の効率的な勉強法を教えてください
理論を単体で暗記せず、必ず提唱者とセットで覚えることが重要です。人物名と理論名を入れ替えた選択肢が定番のためです。発達段階を扱う理論は段階の順序が問われるので、図や表にまとめて視覚的に整理すると定着しやすくなります。
ピアジェの認知発達段階を教えてください
感覚運動期、前操作期、具体的操作期、形式的操作期の4段階です。前操作期の自己中心性やアニミズム、具体的操作期で成立する保存の概念など、各段階に特徴的な現象があわせて問われます。段階の順序と特徴を対応させて覚えましょう。
エリクソンの発達段階では何を押さえればよいですか
各段階における心理社会的危機の対立軸を覚えることが中心です。乳児期は基本的信頼対不信、幼児期前期は自律性対恥・疑惑、幼児期後期は自主性対罪悪感にあたります。保育に関わる乳幼児期の段階は特に重点的に確認しましょう。
愛着（アタッチメント）の分類を教えてください
エインズワースのストレンジ・シチュエーション法により、安定型、回避型、抵抗型（アンビバレント型）、無秩序・無方向型に分類されます。それぞれ養育者との分離時と再会時の子どもの反応が異なるため、行動の特徴とあわせて整理しておきましょう。
パーテンの遊びの分類を教えてください
何もしていない行動、一人遊び、傍観者的行動、平行遊び、連合遊び、協同遊びに分類されます。年齢とともに社会的な関わりが深まっていく流れとして捉えると覚えやすくなります。平行遊びと連合遊びの違いが問われやすい論点です。
