教育原理の出題範囲

教育原理は、教育の基本法令・理念から西洋教育思想まで幅広く問われる科目です。ルソー・ペスタロッチ・フレーベルなどの教育哲学者や、幼稚園教育要領が頻出です。

  • 教育基本法・学校教育法
  • 幼稚園教育要領
  • 西洋教育思想（ルソー・ペスタロッチ・フレーベルなど）
  • 日本の教育史
  • 特別支援教育
  • 生涯学習・社会教育

頻出テーマと学習ポイント

教育基本法・学校教育法の要点

教育基本法と学校教育法の条文内容の違いを正確に把握することが重要です。教育の目的・目標、義務教育、幼稚園の目的・目標など、条文に即した出題が多いため、原文に近い形で理解しておきましょう。

  • 教育基本法
  • 学校教育法
  • 幼稚園教育要領
  • 義務教育
  • 教育の目的

西洋教育思想の人物と理念

ルソー（自然主義・「エミール」）、ペスタロッチ（直観教育・貧民学校）、フレーベル（幼稚園創設・恩物）、コメニウス（「大教授学」）など、人物・著書・思想のセット暗記が必須です。

  • ルソー
  • ペスタロッチ
  • フレーベル
  • コメニウス
  • デューイ

特別支援教育と生涯学習

特別支援教育では個別の教育支援計画・指導計画の違いや、インクルーシブ教育の理念が問われます。生涯学習では社会教育法・公民館・図書館の役割も出題されます。

教育原理の例題

実際に出題される形式の一部です。緑色が正解の選択肢です。残り110問は「クイズをはじめる」から無料で解けます。

例題 1

教育基本法(平成18年全部改正)第1条「教育の目的」に関する記述として、正しいものを一つ選びなさい。

  1. 教育は、人格の完成を目指し、平和で民主的な国家及び社会の形成者として必要な資質を備えた心身ともに健康な国民の育成を期して行われなければならない
  2. 教育は、知識及び技能の伝達を通して、優秀な産業人を育成することを第一の目的とする
  3. 教育は、国家への忠誠心と愛国心の涵養を最優先の目的とする
  4. 教育は、個人の学力向上と進学実績の向上を目的として行われる

正解：A　教育基本法第1条は「教育は、人格の完成を目指し、平和で民主的な国家及び社会の形成者として必要な資質を備えた心身ともに健康な国民の育成を期して行われなければならない」と規定する。「人格の完成」を目的の第一に掲げている点が重要であり、条文の冒頭部分は頻出事項。

例題 2

学校教育法が定める幼稚園の目的として、正しいものはどれか？

  1. 義務教育の基礎を培うものとして、幼児を保育し、その心身の発達を助長する
  2. 義務教育及びその後の教育の基礎を培うものとして、幼児を保育し、その心身の発達を助長する
  3. 小学校教育の内容を先取りして指導し、就学の準備を整える
  4. 保護者の就労等により保育を必要とする幼児を、日々保護者に代わって保育する

正解：B　学校教育法第22条は「幼稚園は、義務教育及びその後の教育の基礎を培うものとして、幼児を保育し、幼児の健やかな成長のために適当な環境を与えて、その心身の発達を助長することを目的とする」と規定しています。誤答として狙われるのは「義務教育の基礎」と「義務教育及びその後の教育の基礎」の違いです。幼稚園は小学校の準備機関ではなく、その後の教育まで見据えた基礎を培う場と位置づけられています。なおDは、児童福祉法における保育所の説明です。

例題 3

ルソーが著書「エミール」で唱えた教育観として正しいものはどれか？

  1. 軍事訓練を基礎とした教育
  2. 自然に従った教育
  3. 読み書きそろばんの反復練習
  4. 宗教的修行としての教育

正解：B　ルソー（1712-1778）は著書『エミール』（1762年）で「自然に従った教育」を唱え、子どもの自然な成長を尊重する教育論を展開しました。大人が一方的に知識を詰め込むのではなく、子どもの発達段階に応じて環境を整えるという考え方で、「子どもの発見者」とも呼ばれます。

例題 4

ペスタロッチが提唱した教育の特徴として正しいものはどれか？

  1. 直観教授・家庭的環境での教育
  2. 体罰による規律指導
  3. エリート育成のための選抜教育
  4. 宗教的修行としての教育

正解：A　ペスタロッチ（1746-1827）は感覚的直観を重視した「直観教授」を提唱し、家庭的な愛情に基づく教育環境の重要性を説きました。孤児の教育に生涯を捧げ、「生活が陶冶する」という言葉でも知られます。ルソーの影響を受けつつ、それを実践に移した人物として位置づけられます。

例題 5

ジョン・デューイが提唱した教育の考え方として正しいものはどれか？

  1. 経験主義教育・問題解決学習
  2. 修道院式の規律教育
  3. 軍事訓練を基礎とした教育
  4. 読み書きそろばんの反復練習

正解：A　デューイ（1859-1952）は「経験主義教育」を提唱し、「なすことによって学ぶ」を掲げて問題解決的な学習を重視しました。シカゴ大学に実験学校を設立し、子どもの生活経験を出発点とする教育を実践しています。教師が知識を一方的に伝える伝統的教育への批判という文脈で理解しましょう。

よくある質問

教育原理の効率的な勉強法を教えてください
「法令」と「思想家」の二軸で進めるのが効率的です。教育基本法や学校教育法は条文の文言そのものが問われるため、キーワードを正確に覚えます。思想家は人物・著書・キーワードを一覧表にまとめ、一問一答で繰り返し確認すると混同を防げます。
教育原理でよく出る西洋の教育思想家は誰ですか
ルソー（『エミール』・消極教育）、ペスタロッチ（直観教授・シュタンツ）、フレーベル（恩物・世界初の幼稚園）、コメニウス（『大教授学』・世界初の絵入り教科書）、デューイ（経験主義・シカゴ大学実験学校）が代表格です。著書名と人物の組み合わせを入れ替えた選択肢が定番なので、対応関係を正確に押さえましょう。
教育基本法ではどこを押さえればよいですか
冒頭の「教育の目的」にある人格の完成という文言は必出級です。あわせて教育の機会均等、義務教育、生涯学習の理念、学校教育、家庭教育、幼児期の教育に関する条文を確認しましょう。似た表現が並ぶため、どの条文の文言かまで意識して読むことが得点につながります。
教育原理と保育原理はどう学び分ければよいですか
教育原理は学校教育制度と教育思想全般、保育原理は保育所保育指針を中心とした保育実践が主な範囲です。ただしフレーベルやモンテッソーリなど人物は両科目で問われます。人物・思想は共通の一覧表を作り、法令部分だけ科目別に分けて学習すると効率的です。
特別支援教育では何が問われますか
インクルーシブ教育システムの考え方、合理的配慮、そして「個別の教育支援計画」と「個別の指導計画」の違いが頻出です。前者は関係機関と連携した長期的な支援計画、後者は指導内容を具体化した計画である点を区別して覚えましょう。
教育原理は社会的養護と一緒に受けたほうがよいですか？
同じ回の筆記試験で受けてください。教育原理と社会的養護は、両科目とも満点の6割以上を得点した人が合格となり、片方だけ6割を超えても合格になりません。教育原理だけ得点できても社会的養護が届かなければ、両方とも受け直しになります。受験する回を決めたら2科目を並行して直前まで学習し、片方だけ先に仕上げないことが大切です。教育原理は50点満点・30分と他科目の半分の規模で、1問あたりの重みが大きい点にも注意してください。
