子ども家庭福祉の出題範囲

子ども家庭福祉は、子どもと家庭を取り巻く法律・制度を学ぶ科目です。児童福祉法・子どもの権利条約・子ども・子育て支援新制度などが中心的な出題テーマです。

  • 児童福祉法・子どもの権利条約
  • 子ども・子育て支援新制度
  • 児童虐待防止法・対応
  • 少子化対策・ひとり親家庭支援
  • 障害児支援制度
  • 子どもの貧困対策

頻出テーマと学習ポイント

児童福祉法と子どもの権利条約

児童福祉法の目的・対象・定義（児童の年齢区分）と国連子どもの権利条約の4つの権利（生きる権利・育つ権利・守られる権利・参加する権利）を正確に把握しましょう。条約の批准年（1994年）も頻出です。

  • 児童福祉法
  • 子どもの権利条約
  • 4つの権利
  • 児童の定義
  • 最善の利益

子ども・子育て支援新制度

2015年施行の子ども・子育て支援新制度では、認定こども園・保育所・幼稚園の違いや給付の仕組みが重要です。地域型保育事業（小規模保育・家庭的保育・居宅訪問型・事業所内保育）の4種類も押さえましょう。

  • 認定こども園
  • 地域型保育事業
  • 小規模保育
  • 施設型給付
  • 子育て支援

児童虐待防止と対応

虐待の4種類（身体的・心理的・性的・ネグレクト）の定義と、児童相談所・市区町村の役割分担を整理しましょう。通告義務や一時保護の要件も出題されます。要保護児童対策地域協議会の機能も重要です。

  • 虐待の4種類
  • 児童相談所
  • 一時保護
  • 通告義務
  • 要保護児童

例題 1

児童相談所に関する記述として、正しいものを一つ選びなさい。

  1. 児童福祉法に基づき、都道府県及び指定都市に設置が義務づけられているほか、中核市及び特別区にも設置が認められている
  2. 市町村に設置義務があり、すべての市町村に設置されている
  3. 児童相談所の所長は、必ず医師でなければならない
  4. 一時保護の期間は原則1か月以内と定められており、延長は認められない

正解：A　児童相談所は児童福祉法第12条に基づき、都道府県・指定都市に設置義務があり、中核市・特別区にも設置が認められている(政令指定児童相談所設置市)。市町村には設置義務はない(Bは誤り)。所長の資格要件は医師に限定されない(Cは誤り)。一時保護の期間は原則2か月を超えてはならないが、必要な場合は延長が認められ、親権者が同意しない場合等は家庭裁判所の承認が必要(Dは誤り)。

例題 2

児童福祉法における「児童」の定義として正しいものはどれか？

  1. 満15歳未満の者
  2. 満18歳未満の者
  3. 満20歳未満の者
  4. 満16歳未満の者

正解：B　児童福祉法第4条において「児童」とは「満18歳に満たない者」と定義されています。同法ではさらに乳児（満1歳未満）、幼児（満1歳から小学校就学前）、少年（小学校就学から満18歳未満）に区分されます。法律によって「児童」の範囲が異なる場合があるため、まず児童福祉法の定義を基準に覚えましょう。

例題 3

保育所に通う子どもが虐待を受けていると疑われる場合、保育士がとるべき最初の行動はどれか？

  1. 保護者に直接問い詰める
  2. 自分だけで解決しようとする
  3. 市区町村・児童相談所に通告する
  4. 他の保護者に相談する

正解：C　児童虐待防止法では、虐待を受けたと思われる児童を発見した者は速やかに市区町村・福祉事務所または児童相談所に通告しなければならないと定めています。この義務は「思われる」段階で生じ、確証は必要ありません。また通告は守秘義務違反にはあたらないとされている点も重要です。

例題 4

「要保護児童対策地域協議会」に関する記述として、正しいものを一つ選びなさい。

  1. 児童福祉法に基づき、地方公共団体が設置に努めるものとされている
  2. 構成員は守秘義務を負い、協議会で知り得た情報を他に漏らしてはならない
  3. 要保護児童・要支援児童・特定妊婦を対象として、関係機関の連携のもと支援を行う
  4. 上記のすべてが正しい

正解：D　要保護児童対策地域協議会(要対協)は、児童福祉法第25条の2に基づき地方公共団体が設置する努力義務を負う(設置率は現在ほぼ100%)。対象は要保護児童・要支援児童・特定妊婦であり、関係機関(児童相談所・市町村・保健所・医療機関・警察・学校・保育所等)の連携・情報共有のもと支援を行う。構成員には法律上の守秘義務が課される(同法第25条の5)。全選択肢が正しいので正解はD。

例題 5

児童虐待防止法における虐待の4類型として正しいものはどれか？

  1. 身体的・性的・ネグレクト・心理的
  2. 身体的・性的・経済的・心理的
  3. 身体的・性的・ネグレクト・経済的
  4. 暴力・性的・育児放棄・言語的

正解：A　児童虐待防止法では「身体的虐待」「性的虐待」「ネグレクト」「心理的虐待」の4種類が定義されています。「経済的虐待」は高齢者虐待防止法や障害者虐待防止法に規定されるもので、児童虐待の類型には含まれません。子どもの前で配偶者に暴力をふるう面前DVは心理的虐待にあたります。

よくある質問

子ども家庭福祉の効率的な勉強法を教えてください
児童福祉法と子どもの権利条約を土台に据え、そこから各種施策へ広げるのが効率的です。この分野は法改正や新制度の創設が多いため、古い教材の記述をそのまま覚えないよう注意しましょう。制度名と目的をセットで整理するのがコツです。
子どもの権利条約の4つの権利とは何ですか
生きる権利、育つ権利、守られる権利、参加する権利の4つです。あわせて「子どもの最善の利益」という基本原則が繰り返し問われます。条約の理念が児童福祉法にどう反映されているかまで確認しておくと、応用的な設問にも対応できます。
児童虐待にはどのような種類がありますか
身体的虐待、性的虐待、ネグレクト、心理的虐待の4種類です。子どもの前で配偶者に暴力をふるう面前DVは心理的虐待に含まれる点が頻出です。具体的な事例がどの類型にあたるかを判断させる形式で問われます。
児童相談所の役割を教えてください
相談の受付、調査・診断・判定、一時保護、施設入所などの措置が主な業務です。虐待を受けたと思われる児童を発見した場合の通告義務は保育士に限らずすべての人にあり、この点は繰り返し問われています。市町村との役割分担も確認しておきましょう。
子ども・子育て支援新制度では何を押さえればよいですか
認定こども園の類型（幼保連携型・幼稚園型・保育所型・地方裁量型）と、地域型保育事業の4種類（小規模保育・家庭的保育・事業所内保育・居宅訪問型保育）が中心です。施設型給付と地域型保育給付の区別もあわせて整理しておきましょう。
