保育実習理論の出題範囲

保育実習理論は、音楽・造形・言語の表現技術と保育実習の知識を問う科目です。楽典（音楽理論）の問題が多く含まれており、他科目と傾向が異なる実技系科目です。

  • 保育実習の意義と目的
  • 音楽表現（楽典・コード・移調）
  • 造形表現（素材・技法・色彩）
  • 言語表現（絵本・紙芝居・手遊び）
  • 保育所・施設での実習指導
  • 保育課程・指導計画の作成

頻出テーマと学習ポイント

楽典（音楽理論）の基礎

保育実習理論で最も出題が多いのが楽典です。音符・休符の長さ、拍子記号（4/4・3/4・6/8拍子）、移調（ハ長調→ト長調など）、コードネーム（C・Dm・G7など）を練習問題で繰り返し学習しましょう。

  • 移調
  • コードネーム
  • 拍子記号
  • 音符・休符
  • ハ長調・ト長調

造形表現と色彩の基礎

色の三原色（赤・青・黄）と光の三原色（赤・緑・青）の違い、色相・明度・彩度の概念を整理しましょう。版画・紙工作・粘土などの素材・技法の特徴、また子どもの絵の発達段階（なぐり描き・象徴期・写実期）も出題されます。

  • 色の三原色
  • 色相・明度・彩度
  • 版画技法
  • 子どもの描画発達
  • 造形活動

保育実習と指導計画

実習日誌の書き方（エピソード記録・観察記録）と指導案（部分実習・全日実習）の構成要素を理解しましょう。年間計画・月案・週案・日案の関係性、絵本・紙芝居・人形劇など言語表現の特徴も頻出です。

  • 実習日誌
  • 指導案
  • 部分実習
  • 絵本・紙芝居
  • 言語表現

保育実習理論の例題

実際に出題される形式の一部です。緑色が正解の選択肢です。残り107問は「クイズをはじめる」から無料で解けます。

例題 1

短音階に関する記述として、誤っているものを一つ選びなさい。

  1. イ短調の自然的短音階は、ラ・シ・ド・レ・ミ・ファ・ソ・ラである
  2. 旋律的短音階は、下行するときも第6音と第7音を半音上げたまま演奏する
  3. 和声的短音階は、自然的短音階の第7音を半音上げた音階である
  4. 短音階では、主音から第3音までの音程が短3度になる

正解：B　旋律的短音階は、上行するときに第6音と第7音を半音上げ、下行するときはもとの自然的短音階と同じ音で演奏する。下行するときも半音上げたままとするBは誤り。イ短調の自然的短音階は、ラ・シ・ド・レ・ミ・ファ・ソ・ラである(A)。和声的短音階は、自然的短音階の第7音を半音上げた音階で、イ短調ではソがソ♯になり、第7音から主音までが半音になる(C)。短音階では主音から第3音までが短3度、長音階では長3度になる(D)。

例題 2

ローウェンフェルド(V. Lowenfeld)らの子どもの描画発達段階に関する記述として、最も適切なものを一つ選びなさい。

  1. 「なぐりがき期」では点や線を描くこと自体を楽しみ、やがて描いたものに名前をつけるようになる。
  2. 「図式期」は1歳前後にみられ、頭から直接手足が出た頭足人を描くことが特徴の時期である。
  3. 画面の下端に地面を表す線(基底線)が現れるのは、なぐりがき期の初期の特徴である。
  4. 描画発達には順序性がなく、どの段階からでも自由に飛び越えて到達するとされる。

正解：A　なぐりがき期(錯画期、おおむね2〜4歳頃)は、腕の運動として点や線を描くことを楽しみ、後半には描いたものに命名する姿(象徴期・命名期)がみられる。頭足人は前図式期(4〜7歳頃)に多くみられ、図式期を1歳前後とするBは誤り。基底線が現れるのは図式期であり、なぐりがき期初期とするCも誤り。描画は運動→象徴→図式へとおおむね順序をもって進むため、順序性がないとするDも誤り。

例題 3

保育で用いる描画材の特徴に関する記述として、誤っているものを一つ選びなさい。

  1. クレヨンやパスは、筆圧をかけずに描けるため、乳幼児が初めて用いる描画材として扱いやすい。
  2. 水彩絵の具は水の量によって濃淡や広がりが変わり、にじみやぼかしなどの表現が楽しめる。
  3. パスはクレヨンよりも硬く、色を混ぜたりぼかしたりすることが難しい。
  4. クレヨンで描いた上から水彩絵の具を塗ると、油分が絵の具をはじく性質を利用したはじき絵(バチック)ができる。

正解：C　パス(オイルパステル)はクレヨンより油分が多くやわらかいため、色を重ねたり、指でこすって混ぜたり、ぼかしたりしやすい。クレヨンはパスより硬めで、線をかくのに向いている。パスのほうが硬く混色やぼかしが難しいとするCは誤り。クレヨン・パスの扱いやすさ(A)、水彩絵の具の濃淡やにじみ(B)、クレヨンの油分を生かしたバチック(D)はいずれも正しい。素材の性質を知り、ねらいに応じて選ぶことが大切である。

例題 4

紙芝居やパネルシアターなどの児童文化財に関する記述として、誤っているものを一つ選びなさい。

  1. パネルシアターは、古宇田亮順が1973年に考案し、名づけたものである
  2. 街頭紙芝居は、テレビ放送が普及した昭和30年代以降に始まった
  3. ペープサートは、永柴孝堂によって名づけられ、戦後に児童文化財として広まった
  4. 高橋五山は、幼稚園向けの紙芝居を刊行し、教育紙芝居の普及に努めた

正解：B　街頭紙芝居は昭和初期(1930年頃)に始まり、『黄金バット』などが人気を集め、戦後も多くの紙芝居屋が活動したが、昭和30年代にテレビ放送が普及すると衰退していった。テレビ放送が普及した昭和30年代以降に始まったとするBは誤り。パネルシアターは、古宇田亮順が1973年に考案して名づけたもので、毛羽立った布を張ったパネルに不織布の絵を貼ったり外したりして演じる(A)。ペープサートは、paper puppet theater を略した名称で、永柴孝堂が名づけ、戦後に児童文化財として広まった(C)。高橋五山は、昭和10年(1935年)頃に幼稚園向けの紙芝居を刊行し、教育紙芝居の普及に努めた(D)。

例題 5

音楽教育の方法と、それを提唱した人物の組み合わせに関する記述として、誤っているものを一つ選びなさい。

  1. リトミックは、ダルクローズ(É. Jaques-Dalcroze)が創始した、身体運動を通して音楽的感覚を養う教育法である。
  2. オルフ(C. Orff)の音楽教育は、オルフ楽器などを用いた即興や合奏を重視する。
  3. コダーイ(Z. Kodály)の音楽教育は、自国の民謡やわらべうた、歌唱、ハンドサイン等を活用する。
  4. スズキ・メソード(才能教育)は、コダーイが提唱した、読譜訓練を最優先する教育法である。

正解：D　スズキ・メソード(才能教育)を提唱したのは鈴木鎮一であり、母語を覚えるように耳から繰り返し親しむことを重視する方法で、「コダーイが提唱」「読譜訓練を最優先」とするDは人物・内容ともに誤り。A(ダルクローズのリトミック)、B(オルフの合奏・即興)、C(コダーイの歌唱・わらべうた・ハンドサイン)は正しい。

よくある質問

保育実習理論の効率的な勉強法を教えてください
楽典は知識の暗記だけでは解けないため、実際に手を動かす演習が欠かせません。移調やコードネームは繰り返し解くことで確実に得点源にできます。造形や言語の分野は用語と技法名を整理し、一問一答で確認するのが効率的です。
楽典ではどのようなテーマが頻出ですか
移調、コードネーム、拍子記号、音符と休符の長さ、調号が中心です。いずれも計算や読み取りを伴うため、知識を覚えるだけでなく実際に問題を解いて慣れることが重要です。楽譜を見て答える形式に早めに慣れておきましょう。
移調の解き方を教えてください
元の調と移調先の調が何度離れているかを数え、すべての音を同じ幅で移動させるのが基本です。あわせて調号も移調先のものに置き換えます。まずはハ長調とト長調など身近な調の関係から練習すると理解しやすくなります。
コードネームの読み方を教えてください
アルファベットが根音を表し、そこに和音の種類が付きます。たとえばCはド・ミ・ソ、Amはラ・ド・ミの構成音です。長三和音と短三和音の違いを理解したうえで、主要な和音の構成音を覚えると解答が速くなります。
造形分野では何を押さえればよいですか
色の三属性である色相・明度・彩度と混色の考え方が基本です。あわせて版画などの技法名、子どもの描画の発達過程（なぐりがきから象徴的な表現、図式的な表現へ）を押さえましょう。技法名と特徴を結びつけた出題が多く見られます。

実技試験について

保育実習理論を含む筆記試験の全科目に合格すると、実技試験に進みます。音楽・造形・言語の3分野のうち、あらかじめ2分野を選択して受験します。

音楽に関する技術 課題曲をピアノまたはギターで伴奏しながら歌います。弾き歌いの練習が必要になるため、音楽経験がない方は準備期間を長めに見ておくと安心です。
造形に関する技術 当日示される条件にもとづき、保育の一場面を絵画で表現します。時間内に描き上げる練習が欠かせません。
言語に関する技術 子どもに向けた話を、絵本や道具を使わずに口演します。時間配分と声の出し方の練習が中心になります。

3分野の比較と選び方をくわしく見る

※ 課題曲や実施要領は年度によって変わります。受験の際は必ず一般社団法人 全国保育士養成協議会の公式情報をご確認ください。
