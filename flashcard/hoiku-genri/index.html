保育原理の出題範囲

保育原理は保育士試験の必須科目です。保育所保育指針を中心に、保育の基本理念・歴史・方法・環境構成などが問われます。全9科目の中でも出題範囲が広く、得点源となる重要科目です。

  • 保育所保育指針
  • 保育の基本理念・原則
  • 保育の歴史（日本・海外）
  • 保育の形態・方法
  • 保育環境の構成
  • 保護者支援・地域支援

頻出テーマと学習ポイント

保育所保育指針の理解

保育所保育指針は保育原理の最重要テーマです。養護と教育の一体的展開、乳児保育・1歳以上3歳未満・3歳以上の各年齢区分の内容、保育の目標・方法・環境を正確に把握しましょう。改定のポイントも頻出です。

  • 保育所保育指針
  • 養護と教育
  • 乳児保育
  • 保育の環境
  • 計画と評価

保育原理の例題

実際に出題される形式の一部です。緑色が正解の選択肢です。残り112問は「クイズをはじめる」から無料で解けます。

例題 1

保育所保育指針における5領域として正しいものはどれか？

  1. 健康・人間関係・環境・言葉・表現
  2. 健康・社会・環境・言語・表現
  3. 身体・人間関係・自然・言語・造形
  4. 運動・人間関係・環境・言葉・表現

正解：A　保育所保育指針の5領域は「健康」「人間関係」「環境」「言葉」「表現」です。「言語」ではなく「言葉」、「社会」ではなく「人間関係」である点が誤答として狙われます。5領域は1歳以上の子どもに用いられ、0歳児では3つの視点で示されるという使い分けもあわせて確認しておきましょう。

例題 2

保育所保育指針の現行版が施行されたのはいつか？

  1. 2015年4月
  2. 2018年4月
  3. 2020年4月
  4. 2013年4月

正解：B　現行の保育所保育指針は2017年3月に告示され、2018年4月1日に施行されました。告示の年と施行の年が1年ずれるため、どちらを問われているか注意が必要です。この改定では、乳児保育のねらいが3つの視点で整理され、幼児教育を行う施設としての位置づけが明確化された点が重要です。

例題 3

次の人物と業績の組み合わせとして、正しいものを一つ選びなさい。

  1. ペスタロッチ ─ 1840年にドイツで世界初の幼稚園(キンダーガルテン)を創設し「恩物」を考案した
  2. フレーベル ─ 『隠者の夕暮』を著し、直観教授を基礎とするメトーデ(教授法)を提唱した
  3. モンテッソーリ ─ ローマのスラム街に「子どもの家」を開設し、感覚教具を用いた自己教育を重視した
  4. デューイ ─ ドイツにおいて「労作教育」を提唱し、作業を中心とする学校改革運動を展開した

正解：C　モンテッソーリは1907年にローマに「子どもの家」を開設し、感覚教具を用いた自己教育を確立。Aはフレーベル、Bはペスタロッチの業績で人物が入れ替わっている。Dのデューイは「経験主義教育」を提唱したアメリカの哲学者。「労作教育」はケルシェンシュタイナーの主張である。

例題 4

保育所保育指針(平成29年告示)第1章「総則」に示されている「保育所の役割」に関する記述として、適切でないものを一つ選びなさい。

  1. 保育を必要とする子どもの保育を行い、その健全な心身の発達を図ることを目的とする児童福祉施設である
  2. 入所する子どもの保護者に対する支援及び地域の子育て家庭に対する支援等を行う役割を担う
  3. 保育所における保育は、養護及び教育を一体的に行うことを特性としている
  4. すべての就学前児童に対して、保護者の就労の有無にかかわらず等しく教育を提供する施設である

正解：D　保育所は児童福祉法第39条に基づく「保育を必要とする子ども」を対象とする児童福祉施設であり、就労の有無にかかわらずすべての就学前児童を対象とするものではない(それは認定こども園の機能に近い)。A・B・Cはいずれも保育所保育指針第1章「総則」1「保育所保育に関する基本原則」の(1)「保育所の役割」に明記されている内容である。

例題 5

乳児保育（0歳）のねらい及び内容を示す3つの視点として正しいものはどれか？

  1. 健康・人間関係・表現
  2. 健やかに伸び伸びと育つ・身近な人と気持ちが通じ合う・身近なものと関わり感性が育つ
  3. 生命の保持・情緒の安定・環境への適応
  4. 身体的発達・社会的発達・精神的発達

正解：B　保育所保育指針では、乳児保育のねらい及び内容は「健やかに伸び伸びと育つ」「身近な人と気持ちが通じ合う」「身近なものと関わり感性が育つ」の3つの視点で示されています。これらはそれぞれ心身の健康、人と関わる力、周囲への好奇心に対応し、1歳以上の5領域につながっていきます。

よくある質問

保育原理の効率的な勉強法を教えてください
保育所保育指針の読み込みが学習の軸になります。特に第1章「総則」は繰り返し目を通し、条文の言い回しごと覚えるのが有効です。あわせて倉橋惣三やフレーベルなどの人物は「名前・業績・キーワード」を三点セットで整理し、一問一答で定着させると効率よく得点源にできます。
保育所保育指針はどこを重点的に読めばよいですか
第1章「総則」の保育の目標・保育の方法・保育の環境は最重要です。次に第2章「保育の内容」の、乳児保育の3つの視点と1歳以上児の5領域（健康・人間関係・環境・言葉・表現）を押さえましょう。年齢区分ごとにねらいと内容が整理されているため、表にまとめると混同を防げます。
保育原理でよく問われる人物は誰ですか
日本では倉橋惣三（誘導保育）、野口幽香（二葉幼稚園）、石井十次（岡山孤児院）、赤沢鍾美などが頻出です。海外ではフレーベル、モンテッソーリ、オーエンが問われます。人物名と施設名・著書・思想のキーワードを結びつけて覚えると、選択肢の入れ替え問題に対応できます。
「養護」と「教育」の違いがよくわかりません
養護は「生命の保持」と「情緒の安定」を指し、子どもが安心して過ごせるよう支える営みです。一方の教育は5領域のねらいと内容にもとづく育ちへの働きかけを指します。保育所保育では両者を切り離さず、一体的に展開する点が重要で、ここが選択肢の正誤を分ける論点になります。
保育原理と子ども家庭福祉は何が違いますか
保育原理は保育の理念・内容・保育所保育指針が中心で、子ども家庭福祉は児童福祉法などの制度や施策が中心です。ただし児童福祉施設や子育て支援では出題範囲が重なります。重複する部分は科目をまたいで関連づけて学ぶと、学習時間を短縮できます。
